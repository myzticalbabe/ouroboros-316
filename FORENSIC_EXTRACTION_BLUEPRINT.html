#1 🔴 UJS CAPTCHA BREAKER — ujs_captcha_breaker.py REMAINING · PRIORITY 2

🔄 Repurposes: azazael/src/vision/ocr.py + ujs_portal/docket_retriever.py + browser_base.py
✅ Unblocks Gaps: #17 (Community Care deficiencies status), #24 (ALL BCC court records — any other lawsuits, judgments, filings)

What it does: Solves the UJS Portal CAPTCHA that has been blocking automated docket retrieval. This is the biggest data-access blocker — it gates access to all BCC court records (Auto-FOIA Mailer is now priority #1 because sending requests unblocks more critical gaps).

Implementation approach:

1 Playwright isolates CAPTCHA element → bounding-box screenshot
2 OpenCV preprocesses image (threshold, denoise, remove interference lines)
3 OCR module (azazael/src/vision/ocr.py) reads the text
4 If OCR fails: download audio CAPTCHA .wav → Speech Recognition fallback
5 ⚠ If reCAPTCHA v2/v3 (checkbox/behavioral): OCR won't work — reCAPTCHA uses risk scoring, not text. Fallback: manual browser intervention with human solving in a visible window.
6 Feed solved CAPTCHA + search params → docket_retriever.py → BCCDocketParser
Files to create: Desktop/Libra/scrapers/ujs_portal/captcha_breaker.py (~200 lines)
Dependencies: OpenCV, Pillow, azazael/src/vision/ocr.py, SpeechRecognition (fallback)
⚠ RISK: If UJS Portal uses reCAPTCHA v2/v3 (behavioral scoring, not text OCR), automated solving won't work. The fallback is manual browser intervention.

#2 🚫 SCHEDULE B UN-REDACTOR — schedule_b_unredactor.sh — DEAD END — DO NOT BUILD

#3 🟠 PA CORPORATE RECORDS SCRAPER — pa_dos_corps.py REMAINING · PRIORITY 4

✅ Unblocks Gap: #26 (PA BCO-10) — only remaining item. #6/#7/#8 (board members) were resolved Sessions 11–14 by manual research, so this scraper is demoted.

What it does: Automates searches against the PA Department of State business entity database (corporations.pa.gov) for all 9 board members, finding registered businesses, officer roles, and entity status.

Implementation approach:

1 Playwright navigates to corporations.pa.gov/search/corpsearch

6 Output: board_member_businesses.json with entity details + conflict flags
Files to create: Desktop/Libra/scrapers/pa_dos_corps.py (~250 lines)
Dependencies: Playwright, Desktop/Libra/scrapers/common/browser_base.py
