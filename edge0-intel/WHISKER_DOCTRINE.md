# Whisker Doctrine v1 (2026-09-23) — stress-tested BEFORE adoption.
## Compositional genomes: sockets + whiskers + recipes. Status: DOCTRINE.

### Claim
Genomes are built, not mutated: small measured weight-objects (whiskers)
snapped into standard sockets per a recipe, gated, served, ledgered.

### Evidence audit (for and against, from our own ledger)
- FOR: s05 Ling mechanics exact (readback ~0); task arithmetic is field-
  established; sneg10/no-op proves writes are faithful carriers.
- AGAINST: Gemma dose went BACKWARDS with one whisker (interference at
  n=1); sneg10 = stock (nonlinear response); no combo ever measured.
  Verdict: composition is real but non-trivial. The doctrine stands
  BECAUSE it contains interference measurement (P2), not despite it.

### Socket inventory (measured, not assumed)
- Ling/bailingmoe3: attn_output (1536-axis), ffn_down_exps + shexp (expert-
  last in dq orientation). 24 blocks.
- Gemma-4: attn_output + ffn_down (2560-axis). 42 blocks. No experts.
- Spark2_5: same names, 2560/4096 dims; 1536-vectors correctly SKIP.
- Rule: whiskers never cross archs (shape + coordinate + interface).
  Sockets are per-(arch, layer-block) addressed.

### Whisker provenance bar (library admission)
Every whisker carries: source contrast (prompts + N), socket + layer,
strength validated, single-edit ΔSVI with N>=50, refusal-hash of origin.
No provenance = not a whisker, just a vector. First seeds: 8B refusal
(20.9/1536), Gemma refusal (29.78/2560, flagged BACKWARDS — admitted as
negative control, explicitly marked DO-NOT-DEPLOY).

### Interference taxonomy (what P2 measures)
- additive (independent, predicted by Atlas),
- superadditive (synergy — the prize),
- subadditive/canceling (expected most pairs),
- destructive (caps collapse — gate must catch pre-serve if possible,
  post-eval at latest).
Pairs sampled by attraction (complementary profiles), never exhaustive
(hypergraph result: exhaustiveness formally impossible).

### Genome recipe schema (M5 answered)
{base: {file, sha256}, ops: [{socket, layer, whisker, strength}]...,
 built_by, time} -> deterministic rebuild via gated pipeline. Recipes are
 kilobytes; files are cache. Ledger references recipes, not blobs.

### Failure modes (named in advance)
- Whisker rot: base updates invalidate vectors (re-validate per base).
- Socket drift: arch changes move sockets (gate on dims, already built).
- Attribution debt: n-whisker genomes need factorial ablations; pay with
  fractional designs + surrogate ranking, never full factorial.
- Combination explosion: 50 whiskers -> 1225 pairs; attraction sampling
  + --predict triage only.
- Unification check: crossover (AC/DC, M2N2) IS whisker exchange; ReFT IS
  trained whiskers; TTMM IS per-query whisker selection. One ontology.

### Kill criteria (M8 applied to this doctrine)
- Dead if: 5 measured combos all subadditive-or-worse AND no superadditive
  pair found in 10 attraction-sampled trials.
- Dead if: recipe rebuilds fail determinism check twice (same recipe,
  different bytes/behavior beyond seed noise).
- Downgrade to "single-whisker only" if interference dominates past n=2.

### Relationship to tracks
- Ablation track: single-whisker removal (special case, n=1).
- ReFT track: trained whiskers (Form 1) slot into the same sockets.
- P2/P3: combo measurement + attraction mating under this algebra.
- Atlas: versioned map of whisker effects + recorded interferences.
