### 1. Color-tagging forensics — the phase-1 audit item, resolved by measurement

- **Chrome's JPEG encoder uses FULL-RANGE BT.601, not BT.709.** Probe method: render
  known solid colors (#fff/#f00/#0f0/#00f/#808080/#070b13/#eab973) in Chrome, screenshot
  JPEG, dump raw `yuvj420p` via ffmpeg (must be `yuvj420p`, NOT `yuv420p` — swscale would
  range-compress and invalidate predictions), compare (Y,U,V) against matrix predictions:
  **BT.601 total abs error = 0 (exact), BT.709 = 119** (red Y: measured 76, 601-pred 76,
  709-pred 54). Probe script was one-off and has been deleted.
- **Consequence: do NOT blanket-retag these videos bt709 matrix.** The existing
  `bt470bg` (=BT.601) matrix tag is ACCURATE; forcing bt709 would shift color (red Y
  76→54). Only primaries/transfer were genuinely missing. Correct tag set for this
  pipeline: `range=pc, matrix=bt470bg, primaries=bt709, transfer=bt709` (sRGB
  chromaticities == BT.709; bt709 transfer within noise of the sRGB curve).
- **ffmpeg gotcha: `-color_primaries` / `-color_trc` output options DO NOT reach the
  encoder.** They set AVCodecContext fields that the decoded input frames' own
  properties override — the encode "succeeds" and ffprobe still reads `unknown`.
  `-colorspace`/`-color_range` only *looked* like they worked because the JPEG decoder
  had already set bt470bg/pc on the frames.
- **Verified encode-time fix** (frame-level props win): `-vf
  setparams=range=pc:color_primaries=bt709:color_trc=bt709:colorspace=bt470bg` — now
  wired into `scroll_video.js` `encode()` with the probe rationale in a comment;
  end-to-end verified with a temp capture (probed `pc/bt470bg/bt709/bt709`, then deleted).
- **Verified lossless re-tag fix** for already-shipped files (no re-encode):
  `-c copy -f mp4 -bsf:v hevc_metadata=colour_primaries=1:transfer_characteristics=1:
  matrix_coefficients=5:video_full_range_flag=1 -movflags +faststart`. Two traps:
  (a) `hevc_metadata` options are NUMERIC table E-3/E-4/E-5 values — name form
  (`colorprim=bt709`) dies with "Option 'colorprim' not found"; (b) temp output name
  must keep a `.mp4` extension (or pass `-f mp4`) or the muxer rejects it.
- **Applied 20:14**: both `video/oxford_compact__{oxford,prism}.mp4` now probe as
  `pc / bt470bg / bt709 / bt709`, 1321 frames each, moov-before-mdat intact, byte sizes
  unchanged (in-place VUI flag swap).

  that references it** — the old single shared `#arw` marker rendered every arrowhead
  muted cream. Fix: one marker per role (`arw-forge/mesh/audit/gold`).
